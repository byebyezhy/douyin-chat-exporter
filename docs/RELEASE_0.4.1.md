# v0.4.1：阅读版消息时间

## 用户验收反馈

用户报告 v0.4.0 的实际导出表现良好；对于较长会话，可能需要先手工向上滚到历史起点，程序才会捕获会话标识。用户明确要求本次**不改动捕获流程**，以免影响已有成果。

## 本次变更

- **仅修改本地显示层：** `export-core.js` 的简洁 TXT 与离线 HTML 阅读版。
- 将服务端真实 `createdAt` ISO 时间按 `Asia/Shanghai`（北京时间 UTC+8）展示。
- 按自然日期添加 `YYYY年MM月DD日` 分隔条，正文和成功的语音转写逐条显示 `HH:mm`。
- 缺少可信时间的旧版 DOM 数据只显示正文，不伪造时间；原 JSON 仍保留原始 `createdAt`、服务端消息 ID 等信息。
- 采集、会话绑定、IM 分页、语音请求及断点格式与 v0.4.0 **完全兼容，不做算法改动**。

## 验证

- `npm run check`
- `npm test`，重点涵盖跨北京时间午夜、普通文字、语音转写、缺失时间和 HTML 转义。
- `npm run build`。

安装包依然只有 `douyin-chat-exporter-extension`，不包含 `debugger` 权限。真实私聊内容不上传公开 GitHub。
