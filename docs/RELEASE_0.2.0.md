# v0.2.0 候选版发布与验收

## 一次集成版交付

- 自动从最近列表位置向更早历史滚动；持续快照捕获虚拟列表回收前内容。
- Chrome/Edge MV3 弹出页一次启动，网页悬浮面板负责开始、暂停、继续、停止、断点恢复、删除断点、下载。
- 原生语音转写尝试：严格匹配网页菜单动作；合成右键无法触发时报告 `manual_required`；不调用第三方 ASR。
- 统一输出从旧到新的 JSON/TXT、覆盖率、未分类媒体、语音成功/失败/待处理等状态。
- 最小权限增加 `storage`：用于用户本机可删除的断点，不使用 `unlimitedStorage` 或持久站点权限。

## 自动验证

执行 `npm run check && npm test && npm run build`，CI 生成 `douyin-chat-exporter-extension`。

合成 DOM 测试验证：重叠滚动、虚拟列表窗口回收、覆盖不丢失、断点、原生右键菜单命中及文字追加。所有测试数据均为合成文字。

## 单次真实验收重点

用户在已登录的 Douyin 网页打开一个聊天对象，输入本地标签并开始自动采集。核对：

1. 能否自动滚动到可访问的最早历史、是否异常停止。
2. 真实文本和顺序有无重复/错位；`capture.gapCount` 是否为 0。
3. 发送者、时间与消息类型识别覆盖率（可能 `unknown`）。
4. 语音能否唤起网页自带右键「转成文字」，并正确捕获显示在语音下方的文字；失败是否被标记。
5. 暂停/继续、断点恢复、下载与删除是否正常。

不要上传含私聊内容的导出文件。只反馈脱敏统计及是否存在上述故障。

## 无法承诺的事项

目前没有真实抖音消息 ID/会话 ID、平台分页 `has_more=false` 的证据，不能证明全部历史服务端完整。浏览器可能拒绝合成的右键事件。对这些情况必须报告未验证或待人工处理，不能宣传为已完成的完整备份。
