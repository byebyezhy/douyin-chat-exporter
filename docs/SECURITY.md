# 隐私与安全边界

1. 插件只在用户主动操作后读取当前 `douyin.com` 页面。M0 使用 `activeTab` + `scripting`，不申请持续性域名权限。
2. 用户在抖音官网自行登录。不得要求用户导出 Cookie、Token、登录二维码、HAR、localStorage/sessionStorage 内容或其他凭据。
3. 不包含遥测、远程更新的可执行脚本、聊天内容上传及第三方分析接口。默认输出只在本机。
4. 公开仓库只使用合成数据；Issue/PR/日志不得包含真实私聊、用户 ID、手机号、头像链接或可识别的会话标识。
5. 对外导出文件属于敏感个人数据，UI 应提醒用户妥善保管。不要直接导入未经信任的在线 AI 服务。
6. 按照站点实际访问权限读取本人可见历史，不绕过验证码、封锁、限速或其他账号安全限制。
7. 一旦 M1 需要权限增加，必须在 PR 逐项解释原因并在验收中验证，不能悄悄扩展到 `<all_urls>`。
8. 语音使用抖音网页自带的「转成文字」操作；不上传语音到第三方 AI/ASR 服务，不索取转写平台密钥。对失效/无法转写的条目保留失败状态。
